## 1. Describe your site

From your dashboard, click **AI Generator**, then enter your website's name and a plain-language
description of what it's for. The more specific you are — who it's for, what you want a visitor to
do — the better the first draft.

## 2. Answer the follow-up questions

webma asks a short set of questions (website type, theme, color preference, style) with selectable
options. These materially shape the result, so it's worth answering rather than skipping.

## 3. Generate and preview

Click **Generate Website**. Generation runs in two steps — planning the site's structure, then
writing the code — both shown live so you can see progress rather than staring at a blank loading
state. Once done, you'll see a live, responsive preview you can click through at desktop, tablet, or
mobile widths.

## 4. Edit what you want changed

Click any element in the preview to select it, then describe the change you want in plain language —
this only touches that one section, not the whole site. For precise control, open the code editor and
edit the underlying React/Tailwind directly.

## 5. Export or deploy

When you're happy with it, export the code (ZIP, React, or Next.js project) or deploy straight to
Vercel from the same screen — no separate hosting setup needed.
