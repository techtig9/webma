Most website builders trap you inside their own editor. You can drag blocks around, pick from a theme gallery, and publish — but the moment you want something the builder didn't anticipate, you're stuck. There's no code to fall back on, because there never was any code, just a proprietary layout format.

webma starts from a different premise: describe the site you want, and we generate it as real React and Tailwind CSS — code you can read, edit by hand, hand to another developer, or export and walk away with entirely. The AI does the first draft; you keep full ownership of the result.

## What that looks like in practice

- **Generate** a multi-page site from a plain-language description
- **Preview** it live, click any element, and ask the AI to change just that piece
- **Edit** the underlying code directly in a full editor when you want precise control
- **Export or deploy** — your site, your account, no lock-in
